# Iron Vanguard Studios — Контрольная работа №2

## Тема контрольной работы №2

«CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

## Описание проекта

Сайт-визитка и портфолио инди-студии разработки тактических стратегий **Iron Vanguard Studios**. Проект не является интернет-магазином: цель — презентовать игры студии и собрать базу игроков для закрытых бета-тестов.

## Используемый фреймворк

Bootstrap 5.3.8.

## Способ подключения

Bootstrap подключён через **CDN** (jsDelivr):

```html
<link
  href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/css/bootstrap.min.css"
  rel="stylesheet"
/>
<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/js/bootstrap.bundle.min.js"></script>
```
