# Контрольная работа №2 — Bootstrap Shop

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

## Описание

Проект представляет собой учебную версию сайта интернет-магазина,
разработанную с использованием Bootstrap.

## Практическая работа 9

Выполнена главная страница на Bootstrap-сетке.

Реализовано:

- подключение Bootstrap через CDN;
- подключение `css/custom.css`;
- шапка страницы;
- Bootstrap-навигация;
- hero-блок на сетке;
- блок преимуществ;
- сетка популярных товаров;
- подвал страницы.

## Используемые технологии

- HTML;
- Bootstrap 5.3.3;
- CSS;
- Git;
- GitHub.

## Структура проекта

## Как посмотреть

Открыть файл `index.html` в браузере. Для проверки адаптивности — открыть DevTools
и включить режим эмуляции мобильного устройства.
